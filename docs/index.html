dcss-morgue-report

Turn any Dungeon Crawl Stone Soup player's morgue files into one self-contained, stats-heavy HTML career report — charts, milestone records, per-monster and per-branch breakdowns, layered character portraits wearing the gear they had on, and a searchable table of every run.

Source on GitHub Example reports ↓

What you get

Career overview & records

Games, wins, best score, playtime — plus firsts: first rune, first XL 15, longest game, longest hiatus.

Timeline & archetypes

Games/scores/XL per year, cumulative score, species portraits, background heatmap, and every god with its altar art.

Monsters & branches

Top killers, most-slain uniques and “deaths vs uniques” side by side; branch visits and deaths with each branch's entrance art.

Layered character sprites

Real DCSS part tiles: the species body plus the armour, helm and weapon each character was wearing when the run ended.

Post-mortem per run

Unused escape consumables, chip-death vs one-shot damage math, resist gaps, empty ring slots, never-invoked god abilities — every finding with evidence and one line of advice.

One file, no deps

Pure Python stdlib; art is embedded once, so each report is a single self-contained HTML file that works offline.

Run it yourself

python -m dcssreport all <player>
# open data/reports/<player>.html

Requires Python 3.10+ (standard library only). Morgues are fetched from a DCSS server; the report itself needs no internet once built. --no-tiles builds a text-only report fully offline.
